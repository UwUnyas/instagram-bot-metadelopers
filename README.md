# instagram-bot-metadelopers

## Ссылка на Telegram-бота

Чтобы Instagram-бот показывал кнопку перехода в Telegram, добавьте в **Railway → Instagram service → Variables**:

| Переменная | Значение |
| --- | --- |
| `TELEGRAM_BOT_URL` | Ссылка на бота, например `https://t.me/имя_бота` |

После добавления переменной Railway перезапустит сервис. Instagram-бот будет прикреплять кнопку «Открыть Telegram» к своим ответам; если в меню уже заняты все три кнопки, ссылка придёт отдельной кнопкой следом.

Telegram-бот проверяет подписку на Telegram-канал. Переход по ссылке сам по себе не проверяет Instagram-подписку и не передаёт результат проверки обратно в Instagram-бот.

## Безопасность webhook

Для включения проверки подлинности входящих событий Meta добавьте `META_APP_SECRET` в переменные окружения Railway. При заданном секрете POST `/webhook` принимает только запросы с корректным заголовком `X-Hub-Signature-256` (HMAC-SHA256 по исходному телу запроса). Используйте App Secret именно того приложения Meta, которое отправляет webhook. Не публикуйте секрет и не добавляйте его в Git.

Если `META_APP_SECRET` не задан, бот сохраняет прежнее поведение без проверки подписи и записывает предупреждение в лог. Это сделано для безопасного перехода без внезапного отключения уже работающего webhook.
